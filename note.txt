Adding an Annual Contribution tracker is a powerful way to keep parishioners engaged. It transforms the membership experience from a simple directory into a meaningful journey of stewardship.

To build this, we need a way to store "Donation" records in the database and a visual chart on the member's profile page to show their progress against their pledge or goal.

Step 1: Create the Donation Model (server/models/Donation.js)
We need a separate "drawer" in the toolbox to store every time a member gives.

JavaScript
const mongoose = require("mongoose");

const DonationSchema = new mongoose.Schema({
  memberId: { type: mongoose.Schema.Types.ObjectId, ref: "Member", required: true },
  amount: { type: Number, required: true },
  date: { type: Date, default: Date.now },
  category: { type: String, enum: ["Monthly Pledge", "Special Gift", "Tithes"], default: "Monthly Pledge" },
  note: String
});

module.exports = mongoose.model("Donation", DonationSchema);

Step 2: The Contribution Logic (server/routes/memberRoutes.js)
Add a new route to fetch the total giving for the current logged-in 
member.JavaScript

const Donation = require("../models/Donation");

// Get Member Giving History & Totals
router.get("/contributions/:id", async (req, res) => {
  try {
    const donations = await Donation.find({ memberId: req.params.id }).sort({ date: -1 });
    
    // Calculate total for the current year
    const currentYear = new Date().getFullYear();
    const annualTotal = donations
      .filter(d => new Date(d.date).getFullYear() === currentYear)
      .reduce((acc, curr) => acc + curr.amount, 0);

    res.json({ ok: true, history: donations, annualTotal });
  } catch (err) {
    res.status(500).json({ ok: false, message: "Error fetching contributions" });
  }
});

Step 1: Create the Treasurer's API (server/routes/adminRoutes.js)
We need a backend "door" that specifically handles adding money to
the database and linking it to the correct member.

Add this to your server/routes/adminRoutes.js:

JavaScript
const Donation = require("../models/Donation");

// --- RECORD NEW DONATION ---
router.post("/record-donation", async (req, res) => {
  try {
    const { memberId, amount, category, note, date } = req.body;

    // Create the donation entry
    const newDonation = new Donation({
      memberId,
      amount: parseFloat(amount),
      category,
      note,
      date: date || Date.now()
    });

    await newDonation.save();
    res.json({ ok: true, message: "Donation recorded successfully!" });
  } catch (err) {
    res.status(500).json({ ok: false, message: "Database error recording gift." });
  }
});

Would you like me to show you how to generate a "Tax Receipt" PDF 
for members at the end of the year so they can use it for their 
IRS filings?

Creating an automated Tax Receipt PDF is the ultimate "professional" touch for your church management system. It saves the office weeks of manual work every January and provides parishioners with a secure, official document for their tax filings.

To achieve this, we will use the jsPDF and jspdf-autotable libraries. These allow us to generate high-quality, multi-page PDFs directly in the browser.

Step 1: Install the PDF Libraries
Run this command in your client (frontend) terminal:

Bash
npm install jspdf jspdf-autotable
Step 2: Add the Tax Logic to MemberProfile (MemberProfile.jsx)
We will add a "Generate Tax Report" button to the Stewardship section. This will look at all contributions for the current year, format them into an official letterhead, and download it as a PDF.

1. Add the Imports at the top:

JavaScript

2. Add the PDF Generation function: Paste this inside your MemberProfile component:

JavaScript
  const downloadTaxReceipt = () => {
    const doc = new jsPDF();
    const currentYear = new Date().getFullYear();
    
    // 1. Header & Church Info
    doc.setFontSize(22);
    doc.setTextColor(15, 23, 42); // Dark Blue
    doc.text("Debre Selam Medhanialem", 105, 20, { align: "center" });
    
    doc.setFontSize(10);
    doc.setTextColor(100);
    doc.text("Ethiopian Orthodox Tewahedo Church", 105, 27, { align: "center" });
    doc.text("Aurora, CO | (303) 000-0000 | debre-selam.org", 105, 33, { align: "center" });
    
    // 2. Member Info
    doc.setDrawColor(255, 193, 7); // Gold Line
    doc.setLineWidth(1);
    doc.line(20, 40, 190, 40);
    
    doc.setFontSize(12);
    doc.setTextColor(0);
    doc.setFont("helvetica", "bold");
    doc.text(`Official Tax Receipt - ${currentYear}`, 20, 50);
    
    doc.setFont("helvetica", "normal");
    doc.text(`Member: ${formData.firstName} ${formData.lastName}`, 20, 60);
    doc.text(`Address: ${formData.address || "N/A"}`, 20, 67);
    doc.text(`Date Issued: ${new Date().toLocaleDateString()}`, 20, 74);

    // 3. Donation Table
    const tableData = contributions.history
      .filter(d => new Date(d.date).getFullYear() === currentYear)
      .map(d => [
        new Date(d.date).toLocaleDateString(),
        d.category,
        d.note || "-",
        `$${d.amount.toFixed(2)}`
      ]);

    autoTable(doc, {
      startY: 85,
      head: [['Date', 'Category', 'Note', 'Amount']],
      body: tableData,
      theme: 'striped',
      headStyles: { fillColor: [15, 23, 42] }, // Dark Blue
    });

    // 4. Summary & Legal Footer
    const finalY = doc.lastAutoTable.finalY + 10;
    doc.setFont("helvetica", "bold");
    doc.text(`TOTAL ANNUAL CONTRIBUTION: $${contributions.annualTotal.toFixed(2)}`, 190, finalY, { align: "right" });
    
    doc.setFontSize(9);
    doc.setFont("helvetica", "italic");
    doc.setTextColor(120);
    const footerText = "No goods or services were provided in exchange for this contribution. This church is a 501(c)(3) non-profit organization. Please retain this for your records.";
    doc.text(footerText, 105, 280, { align: "center" });

    doc.save(`${formData.lastName}_Tax_Receipt_${currentYear}.pdf`);
  };
